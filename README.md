# Вариант 20. Конвейер обработки заказов

**СТАРТОВЫЙ ПРОЕКТ ДЛЯ СТУДЕНТА**

**Покрываемые темы:** Channel, producer-consumer, bounded queue, async, errors

## Условия зачёта

Выполнить 7 обязательных заданий. Дополнительные задания повышают оценку. Код должен собираться на .NET 9.
Не допускаются пустые `catch`, блокирующие ожидания в UI-потоке и небезопасное совместное изменение состояния.

## Обязательные задания
1. Создать модель заказа и генератор входных заказов.
2. Реализовать последовательную обработку.
3. Создать bounded Channel для передачи заказов worker-ам.
4. Запустить фиксированное число worker-ов.
5. Собирать успешные результаты и ошибки отдельно.
6. Показать backpressure при заполнении очереди.
7. Корректно завершать writer и дожидаться worker-ов.

## Дополнительные задания
8. Добавить отдельные этапы валидации и обработки.
9. Сравнить производительность при разном числе worker-ов.
10. Сохранять сводку в JSON.

## Требования к сдаче

- Сохранить комментарии `TODO` и заменить их реализацией.
- Добавить отдельные классы для моделей и сервисов.
- Приложить 3–5 тестовых сценариев или пошаговую инструкцию проверки.
- Подготовить устное объяснение архитектуры и одного исправленного дефекта.
